CAD PORTFOLIO STARTER — HOW TO USE

1. Open index.html in a browser to preview the portfolio.
2. Replace the image placeholder panels with your own CAD screenshots/renders. The simplest method is to put image files in this folder and replace each <div class="placeholder">...</div> inside a .visual block with an image, e.g. <img src="ecolube-render.jpg" alt="EcoLube machine CAD render" style="width:100%;height:100%;object-fit:contain">.
3. Replace YOUR_EMAIL@example.com, the WhatsApp placeholder, and LinkedIn placeholder with your actual public contact details.
4. Review every project description and only keep claims that match your completed work.
5. This is a standalone HTML website starter. It is not online yet. To publish free, upload the files to a static hosting service such as GitHub Pages or Netlify, or recreate the content in Google Sites.

The layout is responsive and intended to work on phones and desktop screens.

Contact links are configured: WhatsApp, email, and LinkedIn. The homepage CV button links to https://dareawobiro.cv. cv-for-dare.pdf is kept only as a backup copy.
